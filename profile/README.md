## Engineering principles

- Build real, testable functionality.
- Verify before declaring a task complete.
- Prefer small, auditable changes over opaque automation.
- Protect secrets and customer data.
- Keep production behavior observable and recoverable.
- Never treat a passing mock or simulation as proof of production readiness.

## Repository standards

Projects should document setup, testing, security, deployment, and operational requirements.

Changes that affect production behavior should include appropriate automated verification.
